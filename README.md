# sf69-image

เครื่องสำเร็จรูปสำหรับโปรแกรม "หนังสั้น 69": ComfyUI + ส่วนประกอบติดตั้งไว้แล้ว เปิดเครื่องเช่าแล้วไม่ต้องติดตั้งใหม่

- สร้างอัตโนมัติด้วย GitHub Actions ทุกครั้งที่แก้ `Dockerfile`
- ก้อนที่ได้: `ghcr.io/nikwarakorn9696-dotcom/sf69-image:latest`
- เปลี่ยนฉบับ ComfyUI: แก้ `COMFY_SHA` ใน `Dockerfile` ให้ตรงกับฉบับที่โปรแกรมล็อกไว้
